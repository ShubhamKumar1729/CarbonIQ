# 🌍 AI & ML Carbon Footprint Predictor - Professional Multi-Page Dashboard

A complete, professional full-stack web application featuring multiple pages, advanced data visualization, and Machine Learning integration.

---

## ✨ Features

### 🏠 Multi-Page Structure
- **Home Page**: Landing page with hero section and features
- **Input Page**: Clean form for data entries
- **Dashboard Page**: Advanced analytics with 6+ chart types
- **Suggestions Page**: AI-powered recommendations

### 📊 Advanced Visualization
- **Doughnut Chart**: Emission distribution
- **Bar Chart**: User vs global average
- **Line Chart**: Monthly trend simulation
- **Radar Chart**: Lifestyle impact analysis
- **Progress Bars**: Category-wise breakdown
- **KPI Cards**: Key metrics with animated counters

### 🤖 AI & ML Features
- **Linear Regression**: ML model trained on 300+ samples
- **Dual Calculation**: Formula-based + ML prediction
- **Model Metrics**: R² score, RMSE display
- **AI Recommendations**: Rule-based expert system
- **Impact Estimation**: Quantified CO₂ reduction potential

### 🎨 Professional UI/UX
- **Sidebar Navigation**: Sticky navigation with icons
- **Dark/Light Theme**: Toggle between themes
- **Glassmorphism**: Modern frosted glass effect
- **Gradient Backgrounds**: Professional color schemes
- **Smooth Animations**: Page transitions and counters
- **Responsive Design**: Works on all devices
- **Loading States**: Professional loading overlay
